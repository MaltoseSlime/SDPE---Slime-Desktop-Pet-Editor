# 什麼是史萊姆桌寵編輯器？ / What is SDPE?
史萊姆桌寵編輯器是以scratch式的積木編程邏輯協助使用者製作高度客製化的桌面寵物的桌寵製作器,其主程式功能包括內建的精靈圖編輯器與可微調桌面寵物性格參數的面板，亦提供設計讓桌面寵物之間互動的道具與家具系統。

主程式本身帶有預設組跟簡便設定的功能，若使用者追求更進一步的客製化事件，則要移步至此頁內嵌的積木編輯器進行製作。

 基本上，是一隻貪婪的史萊姆基於對高度客製化又簡易的桌寵引擎的渴望而生的專案。

此專案的發想受"偽春菜"、"shimeji"、"桌寵模擬器"、"動物欄:桌面牧場"啟發。

此專案的目標旨在可離線使用且內容盡可能自定義，進而，此專案並不考慮在未來加入LLM的API串接等功能。



—

Slime Desktop Pet Editor (SDPE) is a Scratch-style block programming tool that helps users create highly customized desktop pets. Its main program features a built-in sprite editor and a panel for fine-tuning desktop pet personality parameters. It also provides a system for designing props and furniture to allow interaction between desktop pets.

The main program itself includes preset groups and easy-to-use settings. For users seeking further customization, they should navigate to the embedded block editor on this page.

Basically, it's a project born from a greedy slime's desire for a highly customizable yet easy-to-use desktop pet engine.

This project was inspired by "Nisemaru," "shimeji," "VPet-Simulator," and "Tiny Pasture."

The goal of this project is to be usable offline and with as much customizable content as possible; therefore, this project does not consider adding features such as LLM API integration in the future.
